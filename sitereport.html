CSY1063 | WEB DEVELOPMENT

Site Report

Introduction

This portfolio website was developed as part of the CSY1063 Web Development assessment. The main purpose of the website is to introduce myself, present my projects and skills, document my learning experience and provide contact information. I developed the website using HTML and CSS and used Git and GitHub to manage the development process.

Learning HTML

One of the first things I learned was how HTML is used to structure a webpage. I learned the importance of using appropriate semantic elements rather than using generic elements for everything. In this portfolio I used elements including header, nav, main, section, article and footer.

Understanding semantic HTML also helped me organise the website into clear sections. I used the navigation element for the main menu because it describes the purpose of that part of the page.

Learning CSS

CSS was used to control the visual appearance and layout of the portfolio. I learned about selectors, margins, padding, borders, typography, Flexbox and CSS Grid. I used Flexbox for navigation and some flexible layouts, while CSS Grid was particularly useful on the projects page.

One challenge I experienced was understanding how spacing and sizing affect the entire page. At first, changing one property sometimes caused unexpected results. By testing the website repeatedly and using browser developer tools, I became more confident in identifying and correcting these problems.

Responsive Design

Responsive design was another important part of the development process. The website needs to work on both desktop and mobile screens, so I used CSS media queries to change layouts at smaller screen sizes. For example, the project and skills grids change from multiple columns to a single column on smaller screens. Navigation and buttons were also adjusted so that they remain usable on mobile devices.

Design Decisions

I chose a simple visual style because the purpose of the portfolio is to communicate information clearly rather than use unnecessary decoration. I used a dark green colour with a white background to provide contrast and keep the pages easy to read. Arial was selected as the main font because it is simple and readable.

I also kept the navigation consistent on every page so that visitors can easily move around the website. The project page uses a different grid arrangement because the assessment specifically requires a different grid layout to demonstrate CSS skills.

Problems and Debugging

During development, I experienced problems with layouts, image sizing and responsive behaviour. For example, some content did not appear correctly when the browser became smaller. I solved these issues by checking my CSS rules, testing different screen widths and using media queries. This taught me that debugging is an important part of web development and that small changes should be tested before moving on.

Git and GitHub

I used Git and GitHub throughout development to record the progress of my portfolio. Instead of uploading the complete website only at the end, I made meaningful commits on separate dates. This allowed me to see how the project developed over time and provided a record of my changes.

Reflection

Overall, this assessment has improved my confidence in creating websites from the beginning. I found CSS layouts and responsive design challenging at first, but repeated practice helped me understand how different properties interact. I also learned that good web development requires testing and debugging rather than expecting the first version of a page to be perfect.

If I developed the portfolio again, I would spend more time planning the layout before writing the CSS. I would also improve the accessibility and visual design further while keeping the website simple and easy to use.
