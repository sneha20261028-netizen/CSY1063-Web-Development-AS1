Site Report

Portfolio Website Development Report

1. Introduction

Developing my portfolio website for CSY1063 Web Development has been an important learning experience. The aim was to create a professional and responsive website that introduces me, presents my skills and projects, provides blog content, and allows visitors to contact me. I developed the website using HTML, CSS and basic JavaScript without using a complete pre-built template.

2. Development Process

I began by planning the required pages: Home, Projects, Skills, Blog, Contact and Site Report. I created the HTML structure first and connected the pages using navigation links. I used semantic elements such as header, nav, main, section, article, figure and footer to organise the content. Semantic HTML provides meaningful structure to web pages (MDN Web Docs, n.d.).

3. Design Decisions

I selected a dark green and neutral colour scheme because I wanted the portfolio to have a professional but distinctive appearance. Dark green was used as the main visual colour, while neutral backgrounds and text colours were used to maintain readability. I used a clean sans-serif typeface because it is easy to read across different screen sizes. Consistent spacing, heading sizes and button styles were used throughout the pages to create visual consistency. I was also influenced by the layout and visual style of Brittany Chiang's portfolio, particularly its use of typography, spacing and navigation. I adapted these ideas to create my own design rather than copying the website.

4. Challenges and Solutions

CSS layout was one of my biggest challenges. I initially struggled with positioning, spacing, image sizing and maintaining consistent layouts. Some images were cropped because of fixed dimensions. I solved these problems by using browser developer tools to inspect elements and adjust the relevant CSS properties. I learned to make smaller changes, test them and identify the actual cause instead of changing several properties simultaneously. This improved my debugging skills and understanding of CSS.

5. Testing and Responsive Design

Responsive design was an important part of development. I used CSS media queries to adapt columns, images, navigation, typography and spacing for smaller screens. I tested the pages using browser responsive tools at different screen widths. I also checked navigation links, images, buttons and form fields. HTML and CSS validation tools were used to identify structural and syntax errors. Alternative text, form labels and semantic HTML were also included to support accessibility.

6. Reflection

The project significantly improved my confidence in HTML, CSS, responsive design, debugging and testing. At the beginning of the module, I found CSS layout and responsive positioning challenging, particularly when images or sections did not appear as expected. Through testing and using browser developer tools, I learned to identify individual problems rather than changing multiple CSS properties at the same time. Git and GitHub also helped me understand version control and the importance of recording development progress. One of the main lessons I learned was that web development requires continuous testing rather than waiting until the end of the project. I became more confident in solving problems independently. However, I still need to improve my JavaScript, accessibility testing and advanced responsive design skills.

7. Conclusion

Overall, creating this portfolio provided practical experience in transforming a planned design into a functional multi-page website. The project allowed me to apply concepts learned during the module while developing my own design style. In future, I would add more advanced JavaScript features, conduct deeper accessibility testing and replace placeholder content with larger projects. This website provides a strong foundation for continuing my web development journey.
