Site Report

My experience of learning web development, design, coding and debugging.

My Development Experience

Developing this portfolio website has been a valuable learning experience because it allowed me to apply the basic web development concepts that I learned during the module. At the beginning of the term, I had a limited understanding of how HTML and CSS work together to create a complete website. I understood some basic HTML elements, but I was not confident about creating a full multi-page website independently.

I started my website by creating the main HTML pages, including the home page, blog, projects, contact page and site report. I learned that HTML provides the structure of a website while CSS is responsible for its visual presentation. Using semantic elements such as <header>, <nav>, <main>, <section>, <article> and <footer> helped me organise the website more effectively.

One of the most challenging parts was CSS. At first, I found positioning, spacing, image sizing and responsive layouts difficult. Sometimes changing one CSS property affected another part of the page. I had problems with images being too large or cropped incorrectly and also had difficulties keeping the layout consistent across different screen sizes. However, debugging these problems helped me understand CSS much better.

I also learned how useful browser developer tools are when debugging a website. I used the browser inspection tools to check elements, experiment with CSS properties and identify layout problems. I gradually learned that debugging is not about getting everything correct on the first attempt. It involves testing, identifying the problem, changing the code and testing again.

Another important part of my development experience was learning about Git and GitHub. I used Git to track changes to my website and pushed my work to GitHub. This helped me understand how developers manage versions of their code and keep a record of development progress.

Reflective Discussion of My Module Experience

Looking back at the module, I can see a clear improvement in my confidence with web development. One of my biggest challenges was understanding why my code sometimes did not produce the result I expected. For example, I initially struggled with CSS layout techniques and image positioning. I sometimes changed several properties without understanding which property was actually causing the problem.

My experience improved when I started making smaller changes and testing them individually. This helped me understand the relationship between HTML structure and CSS styling. I also became more comfortable reading error messages and checking my code carefully rather than immediately replacing the entire section.

There were also positive moments during development. Seeing my website gradually change from simple HTML pages into a complete portfolio was motivating. Creating the navigation, adding images, designing project sections and making the site responsive gave me a better understanding of how professional websites are constructed.

Overall, the module has taught me that web development requires patience and continuous practice. I still have many areas to improve, particularly JavaScript, advanced responsive design and accessibility, but I now feel more confident about continuing to develop my technical skills.

Development of the Website

Stage 1 – Planning

I first planned the structure of my portfolio and identified the pages required for the website. I decided to create a home page, projects page, blog page, contact page and site report.

Stage 2 – HTML Structure

I created the HTML files and connected the pages using navigation links. I focused on using appropriate semantic HTML elements rather than using unnecessary div elements.

Stage 3 – CSS Design

I created a consistent visual style using dark purple backgrounds, lighter text and purple accent colours. I also worked on typography, spacing, buttons, cards and images.

Stage 4 – Testing and Debugging

I tested the website in the browser and corrected problems with images, spacing, navigation and responsive layouts. I also used HTML and CSS validation tools to identify coding errors.

Stage 5 – Final Improvements

Finally, I reviewed the pages for consistency, improved the design, checked the navigation and tested the website on different screen sizes.

Design Decisions

I wanted my portfolio to have a modern and simple visual identity. I selected a dark purple background because it creates a strong contrast with the text and gives the website a modern appearance. Purple is also used as an accent colour for headings, links and interactive elements.

For typography, I chose a clean sans-serif style because it is easy to read on both desktop and mobile screens. I used different font sizes and weights to create a visual hierarchy between headings, paragraphs and navigation links.

The home page was influenced by modern developer portfolio designs that use a large introductory section, a profile image and a short personal introduction. I adapted this idea rather than copying a complete template. I changed the content, colours, structure and sections to make the website suitable for my own portfolio.

I also designed the website with consistency in mind. The navigation, colours, buttons and general spacing are intended to remain similar throughout the different pages so that users can easily understand and navigate the website.

Responsive Design

Responsive design was an important part of the development process. I used CSS media queries to change the layout when the screen becomes smaller. On desktop screens, content can be displayed in multiple columns, while on mobile devices the content is rearranged into a single-column layout.

I also adjusted image sizes, navigation spacing, font sizes and buttons for smaller screens. I tested the website using the browser's responsive design tools to check how the pages behaved at different screen widths.

HTML and CSS Validation

I used the W3C validation services to check the HTML and CSS used throughout my website. Validation helped me identify syntax problems and improve the quality and consistency of my code.
