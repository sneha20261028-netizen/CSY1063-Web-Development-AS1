REFLECTIVE LOG — CSY1063

Site Report

Getting Started

When I started CSY1063 Web Development, my knowledge of HTML and CSS was limited. I understood basic tags, but I was not confident creating a complete website independently. I developed each page separately and added styling gradually. Repeating styles became difficult, so I created a shared CSS file for navigation, typography, colours, spacing and responsive behaviour. This helped me understand the importance of planning and consistency.

Design Decisions

I wanted my portfolio to look personal rather than like a ready-made template. I chose a dark background, light typography and warm amber accents to create a modern technical appearance. I selected Fraunces for headings because its serif style gives the portfolio character, while Inter keeps body text clean and readable. I also used consistent spacing, borders and layouts. Google Fonts supported my typography choices, while MDN Web Docs helped me understand CSS properties and responsive design.

Development Experience

The most challenging part was maintaining consistency across six pages. The Projects page was particularly challenging because it needed individual project cards while demonstrating a different grid arrangement. I also experienced problems with image paths, filenames and positioning. Debugging these issues taught me to check HTML structure and file organisation instead of assuming every problem was caused by CSS. The project improved my confidence with semantic HTML, CSS Grid, Flexbox and reusable styles.

Validation and Accessibility

I checked the website using the W3C Markup Validation Service and the W3C CSS Validation Service . These tools helped identify structural and styling issues before submission. I also used meaningful navigation, labels, alternative image text and clear form controls to improve accessibility. The portfolio was designed to work across desktop, tablet and mobile displays.

Reflection

This project improved my practical understanding of web development. I learned to separate structure from presentation and debug problems systematically. If I completed the project again, I would plan responsive behaviour earlier, organise images from the beginning and create the shared stylesheet before building individual pages. Overall, the project has made me more confident in designing, developing, validating and maintaining a website independently. I also learned that good design requires balancing appearance with usability, readable content and clear navigation. Throughout the process, I reviewed my work regularly and made changes when layouts felt crowded or unclear. This helped me recognise weaknesses, make design decisions, and understand how small improvements can strengthen the user experience. It also encouraged me to think about visitors, accessibility, content hierarchy, usability and future improvements during development.

AI Assistance and Code Acknowledgement

During development, I used ChatGPT as a learning and development support tool to help explain HTML and CSS concepts, identify coding errors and suggest possible improvements. I reviewed the suggestions, adapted the code to my own website and tested the changes before using them. The final page structure, content, styling choices, layout and implementation were reviewed and adjusted by me. Using AI support also helped me understand why particular HTML elements and CSS properties were required rather than simply using code without understanding it.
