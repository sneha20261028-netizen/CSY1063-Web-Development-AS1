Short reflections about my learning experience in web development and Computer Science.

August 2026

Starting My Web Development Journey

Starting web development has helped me understand how websites are structured. Before learning HTML, I mainly saw websites from the user's perspective. Learning HTML helped me understand that every page has a structure made from elements such as headings, paragraphs, links and sections.

I also learned that good website development is not only about making a page look attractive. The structure needs to be logical and easy to navigate. Using semantic elements such as header, nav, main and footer has helped me organise my pages more clearly.

August 2026

What I Learned About CSS

CSS has been one of the most interesting parts of learning web development. It allows me to control colours, spacing, typography and layouts. At first, understanding Flexbox and Grid was difficult because small changes could affect the entire page.

Practising these concepts helped me understand how layouts work. I also learned about media queries, which allow a website to adapt to different screen sizes. Responsive design is important because users can access websites from computers, tablets and mobile phones.

August 2026

Learning Through GitHub

Git and GitHub have helped me understand how developers keep track of changes to their work. Making meaningful commits allows me to record how my portfolio develops over time.

I have learned that version control is useful because mistakes can be identified and previous versions can be reviewed. It also encourages me to develop my website gradually rather than making all changes at once.
