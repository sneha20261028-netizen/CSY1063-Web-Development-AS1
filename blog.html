My Web Development Journey

Building My Portfolio Website

A visual and written explanation of how I designed, developed and improved my personal portfolio website.

Sneha Dhakal · CSY1063 · 2026

01. Introduction

This portfolio website was created as part of my web development learning journey. The main purpose of the website is to introduce myself as a Computer Science student and present my skills, education, projects and learning experiences in one place.

I wanted the website to be simple, professional and easy to navigate. Rather than using excessive animations or complicated visual elements, I focused on readable content, consistent spacing, clear navigation and a simple colour scheme.

02. Home Page

Home page introducing me and my portfolio.

The Home page is the first page visitors see when they open my website. I designed this page to provide a quick introduction and encourage visitors to explore the rest of the portfolio.

The page contains my name, a short introduction, my profile photograph and links to other important sections. The profile image makes the website more personal and helps visitors connect the portfolio with me.

I kept the introduction short because the purpose of the Home page is to give visitors an overview rather than provide every detail immediately.

03. About Me

About Me section explaining my background and interests.

The About Me section gives visitors more information about who I am. It explains my background as a Computer Science student and my interest in technology and web development.

I wanted this section to feel personal rather than looking like a CV. Therefore, I used simple paragraphs to explain my interests, learning journey and goals.

04. Skills Page

Skills page showing my technical and soft skills.

The Skills page presents the abilities I have developed through my studies and practical work. My technical knowledge includes HTML, CSS, Python, SQL and basic JavaScript.

I also included soft skills such as communication, teamwork, problem solving, creativity, time management and adaptability.

Instead of using large skill cards or progress bars, I chose a simple layout because I wanted the information to be clear and easy to read.

05. Education

Education section showing my academic background.

The Education section presents my academic background. It includes my current BSc (Hons) Computer Science degree as well as my previous Grade 12 and Grade 10 education.

Including education on the portfolio gives visitors additional context about my current level of study and the academic foundation behind my technical skills.

06. Projects Page

Projects page displaying my practical work.

The Projects page is one of the most important sections of my portfolio because it demonstrates how I apply the knowledge I have learned.

Instead of only listing project names, I provide information about what each project is, what I worked on and what skills were involved.

This section will continue to grow as I complete more university and personal projects.

07. Blog Page

Blog page documenting my web development journey.

The Blog page is used to document my learning experience. It allows me to explain the development process rather than only showing the final result.

I can use this section to discuss problems I faced, solutions I discovered, new technologies I learned and improvements I made to the website.

08. Contact Page

Contact page providing a way for visitors to reach me.

The Contact page provides visitors with a simple way to communicate with me. It contains my contact information and a basic contact form.

I kept this page simple so that visitors can quickly find the information they need without being distracted by unnecessary elements.

09. Site Report

Site Report documenting the development of my website.

The Site Report explains the development process in more detail. It describes my design decisions, technologies, challenges and improvements.

This section is also useful for reflecting on the work I completed and identifying areas where I can improve my development skills.

10. Design Decisions

Simple visual design used throughout the portfolio.

I selected a black background as the main colour because it gives the website a clean and modern appearance. White and grey are used for readable text, while orange is used as an accent colour.

I deliberately avoided excessive cards, icons and animations. My aim was to create a website that looks like a genuine student portfolio rather than a pre-designed template.

11. Technologies Used

HTML and CSS code used to develop the website.

HTML was used to create the structure of the website. I used semantic elements such as header, nav, main, section, article, footer, headings, paragraphs, lists, tables, forms and images.

CSS was used to control the visual appearance of the website. I used CSS for layout, typography, colours, spacing, navigation, buttons and responsive design.

Flexbox and CSS Grid were also used to arrange different sections of the website and make the layout more flexible.

12. Challenges I Faced

Testing and debugging the website during development.

One of the main challenges was controlling the layout. Sometimes elements became too large, moved to the wrong position or looked different from what I expected.

I also faced problems with images not displaying. This helped me understand the importance of correct file paths, filenames and file extensions.

Another challenge was making the website look simple without making it appear empty. I gradually improved the spacing, typography and content to find a balance between simplicity and useful information.

13. What I Learned

My progress while learning web development.

This project improved my understanding of HTML, CSS, Flexbox, Grid, responsive design and website structure.

I also learned that debugging is an important part of development. Finding and fixing mistakes helped me understand the code instead of simply copying solutions.

Most importantly, I learned that a good website should focus on usability and clear communication as well as appearance.

14. Future Improvements

Areas I would like to improve in the future.

This portfolio is still a work in progress. In the future, I would like to add more projects and improve my knowledge of JavaScript and database technologies.

I would also like to make the contact form fully functional, improve accessibility, add better responsive behaviour and continue refining the design as my skills develop.

15. Conclusion

Final version of my portfolio website.

Creating this portfolio has been an important part of my web development journey. It allowed me to combine the concepts I learned in class and apply them to a complete website.

The website represents my current knowledge, creativity and progress as a Computer Science student. As I continue learning, I expect both my skills and this portfolio to improve.
