Learning Web Development

My journey of learning HTML, CSS and creating my first responsive websites.

14 August 2026

My Journey Into Web Development

Web development is one of the areas of computer science that I have become increasingly interested in. When I first started learning about websites, I was curious about how a simple webpage could be created using code.

I started with HTML, which helped me understand the basic structure of a webpage. I learned how headings, paragraphs, links, images, lists and other elements are used to organise information.

Learning HTML and CSS

After learning the basics of HTML, I started learning CSS. CSS allowed me to change colours, fonts, spacing, layouts and the overall appearance of my webpages.

One of the most useful things I have learned is how to use CSS layouts such as Flexbox and Grid. These tools make it easier to create organised and responsive layouts.

Why Responsive Design Matters

Modern websites are viewed on many different devices, including desktop computers, tablets and mobile phones. Because of this, a website should be easy to use regardless of the screen size.

Using responsive CSS and media queries allows the layout to adapt to different devices. This is something I am continuing to practise while developing my portfolio website.

What I Have Learned

Building websites has taught me that good development is not only about writing code. A successful website should also be accessible, organised, visually appealing and easy to navigate.

I am still developing my skills, but every project gives me an opportunity to learn something new. My goal is to continue improving my knowledge of web development and eventually create more advanced and interactive websites.

Final Thoughts

Learning web development has been a challenging but enjoyable experience. From writing my first HTML page to designing a complete portfolio, I have gained a better understanding of how websites are planned, developed and presented.
