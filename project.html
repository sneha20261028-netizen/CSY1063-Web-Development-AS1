Projects

A selection of projects and practical work I have created while learning programming, web development and technology.

01

Climate Clarity

Climate Clarity is an AI-powered climate information platform designed to make complex climate reports easier for people in Nepal to understand and use.

The platform transforms lengthy climate information into simple summaries, visual data and local climate information through an interactive map covering all 77 districts of Nepal.

HTML CSS AI Data Visualisation

Personal Portfolio Website

My Personal Portfolio Website is a responsive website created to introduce myself and showcase my skills, projects and learning experience as a Computer Science student.

I developed the website using HTML and CSS, focusing on a clean, simple and user-friendly design with multiple pages and clear navigation.

HTML CSS Responsive Design
03

RescueMS — Zoo Management System

RescueMS is a web-based Zoo Management System designed to improve the management of animals, visitors, memberships, sponsorships, events and zoo activities.

The system provides an organised digital platform for zoo staff while making services and information easier for visitors to access.

HTML CSS UI/UX System Design
04

Aura Study

Aura Study is a digital learning platform designed to provide students with a simple and engaging environment for studying and accessing learning resources.

The project explores how web technology and interface design can be combined to organise educational information and create a convenient learning experience.
